## ✨ Features

- **Granular 3-State Controls**: Toggle between **OFF**, **BLUR**, and **HIDE** separately across the **Sidebar** and **Open Chat** views.
  - 👤 **Names**: Blurs or hides conversation list names and sender tags in active chats.
  - 💬 **Messages**: Obfuscates sidebar last message previews and live chat texts.
  - 📷 **Avatars**: Shields profile pictures, group icons, and initials.
- **👁️ Hover Reveal**: Temporarily un-blurs hidden/obscured components simply by hovering your cursor over them.
- **📱 Smart Layout Adaptations**:
  - **Auto Collapse Sidebar**: Collapse the G-Chat sidebar into a minimal status view, expanding it automatically on hover.
  - **Focus Mode**: Dims the sidebar navigation unless focused/hovered to direct all attention to the main chat.
- **📡 Screen Share Guard**: Fully automated real-time blurring the moment your browser detects active tab capture.
- **😱 Panic Mode**: Instant overall full-window blur trigger with a rapid keyboard shortcut.

## ⌨️ Hotkeys Reference

| Shortcut                                             | Action                                                   |
| :--------------------------------------------------- | :------------------------------------------------------- |
| <kbd>⌘ Cmd</kbd> + <kbd>⇧ Shift</kbd> + <kbd>L</kbd> | Cycle **Names** Privacy states (`OFF` ➔ `BLUR` ➔ `HIDE`) |
| <kbd>⌘ Cmd</kbd> + <kbd>⇧ Shift</kbd> + <kbd>P</kbd> | Toggle **Panic Mode** (Full-window blur)                 |
| <kbd>⌘ Cmd</kbd> + <kbd>⇧ Shift</kbd> + <kbd>F</kbd> | Toggle **Focus Mode**                                    |

_Note: Use <kbd>Ctrl</kbd> instead of <kbd>⌘ Cmd</kbd> on Windows/Linux._

## 🛠️ Local Developer Setup

To develop, customize, or audit this extension locally:

### 1. Requirements

Ensure you have [Node.js](https://nodejs.org) (v22+) installed.

### 2. Install Dependencies

```bash
npm install
```

### 3. Start Development Mode

Run the build tool in watch mode. It will automatically compile all TypeScript and resource changes into the `dist/` directory in real-time:

```bash
npm run dev
```

### 4. Load the Extension in Chrome

> [!IMPORTANT]
> **Load the compiled `dist/` directory, NOT the root project folder!**
> The root directory contains raw, un-compiled TypeScript files which Chrome cannot parse. The `/dist` directory contains the fully bundled browser-compatible assets.

1. Open Google Chrome and navigate to `chrome://extensions`.
2. Toggle **Developer mode** (top right corner toggle switch).
3. Click **Load unpacked** (top left corner button).
4. Browse to this project directory and select the **`dist`** folder.
5. Go to [Google Chat](https://chat.google.com) and click the **Blurry GChat** icon in your toolbar to open the operator control panel!

### 5. Code Linting & Formatting

To analyze code for quality issues and automatically format all source files:

```bash
# Run ESLint checks
npm run lint

# Run Prettier formatting
npm run format
```

### 6. Production Compiling & Packaging

To build the fully optimized release and package it into a zip file:

```bash
npm run pack
```

This produces a `blurry-gchat-v1.0.0.zip` archive ready to upload to the Chrome Web Store.

## 🚀 Chrome Web Store Publishing Guide

Follow these steps to publish this extension to the Google Chrome Web Store:

### 1. Developer Console Registration

1. Access the [Chrome Web Store Developer Console](https://chrome.google.com/webstore/devconsole).
2. Sign in with a developer Google account.
3. Pay the one-time registration fee of **$5 USD**.

### 2. Uploading the Archive

1. Click **Add new item** in the console.
2. Upload the `blurry-gchat-v1.0.0.zip` generated by running `npm run pack`.

### 3. Store Listing Guidelines

- **Description**: Highlight features, phims tắt, and emphasize that the extension operates **completely locally** without collecting user data.
- **Icon**: Upload the `icons/icon128.png` file (128x128 pixel).
- **Screenshots**: Upload at least 1-2 screenshots of Google Chat showing the blur controls in action (resolution `1280x800` or `640x400`).

### 4. Privacy & Permissions Justifications

This extension requests certain browser permissions to function. Google reviews these strictly, so use the exact justifications below in the **Privacy Practices** tab to expedite approval:

- **Single Purpose**: `To provide granular privacy controls including blurring and hiding sensitive elements like names and messages on G-Chat.`
- **`storage` permission**: `Used to save user configuration and privacy preferences locally on their device.`
- **`tabCapture` permission**: `Used exclusively to detect screen sharing status and automatically trigger protective privacy shields to prevent accidental data leaks.`
- **Data Collection Declaration**: Check **No, I am not collecting or using user data** (since all logic and settings are computed offline on the client side).
